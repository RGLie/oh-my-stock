# 실적·기업 분석 · v2

지정 종목의 최근 공개된 실적과 IR/SEC 원문을 직접 검색해 읽어라. 입력 기준일 이전에 실제 발표된 최신 보고서를 사용한다. 기업 사업 구조, 경쟁 우위, 매출/마진, 현금흐름, 자본지출, 주식보상과 희석, 부채, 가이던스 변화를 분석한다.

비교 기간, 통화, GAAP/조정 수치, 분기/연간/누적 여부를 확인한다. 숫자와 주석이 충돌하면 원문 위치와 한계를 설명한다. 최신 가격에 의한 밸류에이션은 가격 기준일과 계산 가정을 밝힌다. 컨센서스를 못 구했으면 예상치 대비 평가는 하지 않는다. 기존 투자 근거에 어떤 변화가 있는지, 반대 해석과 다음 확인 지표를 한국어로 정리한다.
