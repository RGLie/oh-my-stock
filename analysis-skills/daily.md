# 데일리 브리프

입력 briefWindow의 한국시간 날짜와 기준 시각을 기준으로, 오늘의 투자 준비에 필요한 짧은 브리핑을 작성한다. 웹에서 실제 자료를 조사한다.

1. 미국장 개장·장중·마감·휴장 여부를 공식 거래소 일정과 확인 가능한 시각으로 구분한다. 한국 날짜와 미국 거래일이 다름을 설명한다. 주말·휴일이면 마지막 거래일 수치와 다음 미국장 일정을 별도로 표시한다.
2. 주요 지수(S&P 500, 나스닥, 다우, VIX)와 필요 시 미 국채금리·USD/KRW를 확인한다. 수치마다 기준 시각/거래일과 변동 기준을 기록한다. 실시간 값을 확보하지 못하면 마지막 종가 또는 미확인으로 명시한다. ETF 가격을 지수 자체로 표시하지 않는다.
3. 한국시간 오늘(dayStartAt~dayEndAt)의 주요 경제 발표·연준 일정·휴장·보유 종목 실적 발표를 찾는다. 이어서 lookaheadEndAt까지 72시간 내 중요 일정도 구분한다. BLS/BEA/Federal Reserve/기업 IR/거래소 원문을 우선한다.
4. 실적 발표일과 컨퍼런스콜 시각을 혼동하지 않는다. 확정 시각이 있는 경우 scheduledAt에 원문 시차를 포함한 ISO 8601 날짜·시간을 넣는다. 장 전/장 후만 확인되면 scheduledAt=null, timing에 날짜와 원문 시간대의 설명을 쓴다. 일정이 추정이면 tentative로 표시한다. 빈 칸을 그럴듯한 시간으로 채우지 않는다.
5. 사건마다 보유 종목과 연결되는 영향 경로, 관찰할 수치, 장기 투자 근거가 바뀔 조건을 한국어로 짧게 제시한다. 투자 성향·목표·유동성 제약을 반영한다. 영향 근거가 부족하면 단정하지 않는다.
6. dailyBrief.date는 입력 briefWindow.date와 일치시킨다. indices와 events의 모든 사실에는 확인한 출처 ID를 붙인다. 확인된 중요 일정이 없으면 빈 events와 확인 범위를 unknowns에 기록한다. 오늘에 맞는 보고서를 만들기 위해 가짜 일정을 생성하지 않는다.
7. dailyBrief.priorities에는 오늘 먼저 볼 것 3~5개를 쓴다. headline/summary는 하루 전체의 핵심, impacts는 포트폴리오 영향, actions는 오늘 확인할 행동을 정리한다. 출처 제목과 설명은 한국어로 작성한다.
