# Oh My Stock

미국 주식·ETF를 중장기로 보유하는 개인 투자자를 위한 로컬 포트폴리오 및 AI 리서치 앱입니다. 토스 잔고와 직접 입력한 보유분을 함께 관리하고, Codex와 Claude가 웹에서 조사한 한국어 분석을 비교합니다.

## 실행

이 PC에는 프로젝트 의존성과 두 CLI가 설치되어 있습니다. **`Start-OMS.cmd`**를 실행하고 [OMS 열기](http://127.0.0.1:4310)로 접속하세요. 터미널에서 `Ctrl+C`를 누르면 서버가 종료됩니다. 이미 실행 중이면 같은 포트로 다시 시작할 필요가 없습니다.

다른 PC에서 처음 설치할 때는 Node.js 24 이상과 pnpm 11이 필요합니다.

```powershell
pnpm install --frozen-lockfile
# .env.example을 참고해 .env를 준비합니다. 기존 .env를 덮어쓰지 마세요.
pnpm build
pnpm start
```

Windows 보조 스크립트는 PATH의 Node.js 또는 Codex 앱의 번들 Node.js를 찾습니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/oms.ps1 dev
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/oms.ps1 build
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/oms.ps1 test
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/oms.ps1 status
```

## PC를 끄고 휴대폰에서 사용하기

OMS와 두 CLI를 Linux VPS에 설치하고 개인 Tailscale HTTPS로 접속하는 구성을 준비했습니다. 이 구성이 배포되면 PC를 꺼도 새 AI 질문·자료 새로고침·기록 열람이 가능합니다. **현재 VPS 배포와 휴대폰 실기기 연결은 미완료**이며 비용과 6개월 청구 조건의 확인이 필요합니다. 사양·비용·설치·데이터 이전 절차는 [클라우드 배포 문서](docs/CLOUD-DEPLOYMENT.md)를 따릅니다.

기본 설정은 계속 localhost 전용입니다. 원격 모드에서는 `.env.example`의 `OMS_REMOTE_ORIGIN`과 `OMS_REMOTE_USER`를 함께 지정하고, 본인 Tailscale 계정을 확인한 요청만 허용합니다. 이 PC에서 원격 값을 미리 입력할 필요는 없습니다.

## 처음 사용할 때

1. **대시보드 → 토스 동기화**로 잔고를 불러옵니다. 여러 계좌라면 설정에서 계좌를 선택합니다. 토스 외 보유분은 **종목 추가** 또는 **CSV 가져오기**로 입력합니다.
2. **설정 및 연결**에서 달러·원화 현금, 현금 확인 여부, 투자 성향과 목표를 입력합니다. 현금을 확인하지 않으면 합계는 보유 주식 평가액만 나타냅니다.
3. **AI 투자 파트너**에 “어도비 최신 실적과 기업 가치를 분석해 줘”처럼 질문합니다. 자동 조사 옵션이 기본으로 켜져 있어 별도의 기사 선택 없이 시작할 수 있습니다.
4. OpenAI·Claude 사용 여부, 모델, 추론 강도를 선택합니다. 실행한 모델·강도 설정은 저장됩니다. 마지막으로 선택한 분석 유형도 확인하세요.
5. 보고서의 핵심 판단 → 주요 수치 → 포트폴리오 영향 순서로 읽고 필요한 행동·리스크·출처를 펼칩니다. **나란히 보기 / OpenAI / Claude**로 읽는 폭을 바꿀 수 있습니다.

보고서 본문은 17px와 넉넉한 줄 간격을 사용합니다. 긴 문장은 원래 내용을 유지하며 문단으로 나누고, 휴대폰에서는 주요 수치를 한 열로 표시합니다. 좁은 화면에서 두 보고서가 억지로 나란히 줄어들지 않도록 자동 배치합니다. 저장한 답변 원문은 변경하지 않습니다.

## 진행 상태·실행 기록·투자 목표

분석을 시작하면 작은 원형 스피너와 함께 **현재 실행 상태 문구, 경과 시간, 검색·원문 확인 횟수**가 표시됩니다. 진행 중에는 서버 상태를 약 1.5초 간격으로 조회합니다. 완료율을 추정하지 않습니다. 운영체제의 ‘동작 줄이기’가 켜져 있어 스피너 애니메이션이 정지해도 경과 시간은 1초마다 갱신됩니다. 상태 갱신이 20초 이상 지연되면 함께 표시합니다.

**AI 실행 기록 → 상세 히스토리**에서 질문·분석 종류·상태로 기록을 찾고 다음 항목을 확인합니다.

- 실행 당시 CLI에 보낸 실제 전송문, 공통 지침, 분야별 분석 기준
- 당시 포트폴리오·투자 성향·목표·참고 자료와 선택 모델·추론 강도
- 최종 답변 원문과 읽기 쉬운 보고서, 실행 활동과 오류
- 모델별 기록 및 JSON 내보내기

기록은 로컬 DB와 전체 백업에 포함됩니다. 모델 내부 사고 과정과 원시 도구 응답은 저장하지 않습니다. 상세 저장 기능 도입 전의 분석은 남아 있는 보고서만 보여주며 당시 전송문을 복원했다고 표시하지 않습니다.

**프롬프트 라이브러리**에서는 10개 분석 기준(주요 뉴스·AI 리밸런싱 제안 포함)과 공통 지침·응답 형식을 확인합니다. 분야별 기준을 편집하거나 기본 내용을 불러와 저장할 수 있습니다. 변경은 다음 분석에 적용되며 과거 기록을 덮어쓰지 않습니다.

**설정 및 연결 → 나의 투자 성향과 목표**에서 성향, 경험, 목표 금액·통화·시점, 감수 가능한 하락률, 가까운 자금 필요, 제외 조건을 입력하세요. 비워 둔 항목을 임의로 추정하지 않도록 지시하며, 다음 AI 분석의 입력에 포함합니다. 수익 보장이나 자동 손절 설정이 아닙니다.

## 데일리 브리프

**AI 투자 파트너 → 데일리 브리프 → 오늘 브리핑 새로고침**을 누르면 선택한 AI들이 공개 자료를 조사하고 전체 포트폴리오를 기준으로 한국어 브리핑을 만듭니다.

- 주요 지수·변동과 기준 시각, 미국장 개장·휴장 상태
- 한국시간 오늘의 경제 발표·실적 일정, 이어서 앞으로 72시간의 주요 일정
- 보유 종목에 미치는 영향, 오늘 먼저 확인할 항목과 출처

한국 날짜와 미국 거래일을 구분하고 주말·휴일에는 마지막 종가와 다음 거래일 일정을 확인하도록 지시합니다. 발표 시각을 확인하지 못하면 시간을 만들어 넣지 않으며 잠정 일정과 구분합니다. 일반 질문의 개별 종목 선택이나 후속 질문을 브리핑에 자동으로 이어 붙이지 않습니다. 예약 실행 기능은 아닙니다.

## 새로고침으로 조사하기

| 분석 카드       | 자동으로 조사·정리하는 내용                                  |
| --------------- | ------------------------------------------------------------ |
| 뉴스 분석       | 기업의 최근 사건, 원문 날짜, 투자 근거에 미치는 영향         |
| 실적·기업 분석  | 최신 IR·공시, 매출·이익·현금흐름, 가이던스, 가치 평가의 가정 |
| 매크로 분석     | 금리·성장·시장 흐름이 보유 자산에 전달되는 경로              |
| 지표 분석       | 물가·고용 지표의 발표 기간과 수정 여부                       |
| 환율 분석       | 달러·원화 흐름, 환율 요인과 원화 평가액 영향                 |
| 포트폴리오 점검 | 집중도·현금·목표 비중과 조정 대안                            |
| 섹터 탐색       | 상대 가치, 이익 변화, 촉매와 가치 함정 가능성                |

카드의 새로고침은 해당 절차를 실행합니다. 대상을 보유 종목 하나로 좁히거나 질문에 보유하지 않은 기업을 입력할 수 있습니다. 두 AI는 같은 시점의 포트폴리오를 받고 각각 웹을 조사하므로 출처와 결론이 다를 수 있습니다.

**분석 기준 편집**에서 절차를 수정할 수 있습니다. 기본 파일은 [`analysis-skills/`](analysis-skills/)에 있으며, 화면에서 저장한 기준은 SQLite에 우선 적용됩니다. 웹 검색을 끄면 선택한 자료만 읽는 분석으로 전환됩니다. 원문 추가는 선택 사항입니다.

진행 상태와 검색·페이지 확인 횟수가 표시됩니다. 취소, 실패한 AI만 재시도, 분석 이력 조회, **이 분석에 이어서 질문**을 지원합니다. 후속 질문에는 해당 AI의 이전 결과만 전달합니다. 재시도는 원래 질문·대상·선택 자료를 유지하되 현재 시점의 공통 지침, 분석 기준, 포트폴리오·투자 성향으로 새 프롬프트를 만듭니다. 과거 기록에 남은 옛 지침이나 삭제된 항목은 다시 전달하지 않습니다.

## 한국어와 원문

보고서, 주요 수치의 설명, AI가 정리한 출처 제목은 한국어가 기본입니다. 기업 IR·공시 등 영문 원문도 조사에 사용하고 원문 URL을 보존합니다. 직접 저장한 자료는 원래 내용을 유지합니다.

리서치 노트의 별도 뉴스 검색은 Google News 한국어 RSS를 사용합니다. 제목·링크만 수집합니다. 기본 검색은 일반 시장 주제입니다. **보유 티커를 Google News 검색에 사용**을 직접 선택하면 티커를 검색어에 포함합니다. 수량·금액·계좌번호는 뉴스 검색어에 포함하지 않습니다.

## CLI 로그인과 모델

두 CLI는 전역 PATH 변경 없이 프로젝트의 `node_modules`에 설치되어 있습니다.

- Codex 로그인: `Login-Codex.cmd`
- Claude 로그인: `Login-Claude.cmd`
- 로그인·버전 확인: `scripts/oms.ps1 status`

기존 공식 CLI 로그인 세션을 인식합니다. 웹사이트 로그인만으로 모든 CLI 권한이 생기는 구조는 아닙니다. 계정의 구독·접근 권한·사용량 한도는 각 CLI가 적용하며, API 키 과금 경로로 자동 전환하지 않습니다.

OpenAI 모델 목록과 지원 추론 강도는 로컬 Codex 모델 캐시에서 읽습니다. Claude는 모델 별칭을 제공하며 정확한 모델 ID도 입력할 수 있습니다. 실제 사용 모델이 CLI 이벤트에 제공되면 보고서에 표시합니다. 지원하지 않는 모델·강도는 실행 오류로 표시됩니다.

## 시세와 계산 범위

- 토스 REST: 계좌, 보유 종목, 현재가, 종목 정보, 일봉, USD/KRW 매매기준율.
- 토스 WebSocket: 체결 시세 구독과 재연결. 구독 연결과 실제 체결 수신 시각을 구분합니다. 장이 닫히거나 거래가 없으면 마지막 가격이 유지됩니다.
- 동기화·시세 갱신·보유 및 현금 변경과 서버 실행 중 15분 간격으로 평가액을 기록합니다. 과거 자산 곡선을 임의로 생성하지 않으며 저장된 기록을 사후에 고치지 않습니다.
- 자산 기록은 **주식 평가액과 현금을 나눠** 저장하고, 직전 기록과 비교해 현금 입력 변경·보유 수량 변경(입금, 출금, 매수, 매도, 토스 동기화)을 **외부 자금 흐름**으로 함께 기록합니다. 대시보드 차트는 세 가지로 볼 수 있습니다. **총자산**은 실제 관측 평가액이며 흐름이 생긴 시점을 점으로 표시하고 마우스를 올리면 내용을 보여줍니다. **주식만**은 현금 입력을 바꿔도 움직이지 않습니다. **성과 지수**는 100에서 시작해 자금 흐름을 제외한 시세 변화만 이어 붙인 값(기말 흐름 기준 수정 디츠 방식)으로, 입금이나 매수 자체는 수익으로 잡히지 않습니다. 분리 기록 이전의 스냅샷은 총자산 보기에만 나타납니다. 흐름은 해당 기록 시점 가격으로 평가하므로 매수 직후 기록 전까지의 가격 변동은 성과에서 제외됩니다.
- 평가손익은 **현재 보유분의 매입원가 대비 손익**입니다. 입출금, 실현손익, 배당·세금·수수료를 반영한 계좌 전체의 TWR/IRR이 아닙니다.
- 달러 기준 합산과 현재 환율의 원화 환산을 제공합니다. 매입 시점 환율 이력이 없어 실제 환차익을 분리 계산하지 않습니다.
- 필요한 시세·환율이 없으면 합계를 `—`로 표시합니다. 오래된 시세는 기준 시각을 함께 표시합니다.
- **AI 리밸런싱 제안** 탭은 선택한 AI가 포트폴리오와 최신 자료를 조사해 종목별 유지·확대·축소·정리와 신규 검토 대상을 제안합니다. 검토용이며 주문 수량·시점을 정하지 않고 실제 주문 기능도 없습니다.
- **대시보드 상단 주요 뉴스**는 선택한 AI 하나가 낮은 추론 강도로 웹을 조사해 지금 알아야 할 뉴스 5~8개를 출처와 함께 정리합니다. 기본 AI는 OpenAI이며, 로그인된 AI만 선택할 수 있습니다. 카드의 톱니 버튼에서 OpenAI·Claude 모델을 따로 지정할 수 있고 이 설정은 카드 전용으로 저장되어 AI 투자 파트너의 모델·강도 설정과 섞이지 않습니다. 각 뉴스에는 **꼭 확인 / 중요 / 참고** 중요도 라벨이 붙습니다. 실제 웹 검색 기록이나 출처를 확인하지 못한 결과에는 경고를 함께 표시합니다. 새로고침으로만 갱신되며 예약 실행은 아닙니다.

## 데이터와 외부 연결

`.env`에는 `TOSS_CLIENT_ID`, `TOSS_CLIENT_SECRET`을 설정합니다. 값은 브라우저에 전달하지 않으며 AI 자식 프로세스의 환경에서도 제외합니다. 서버는 `127.0.0.1`에 바인딩하고 API 출처와 변경 요청 토큰을 확인합니다.

분석 요청 시 포트폴리오·투자 성향과 목표·선택한 자료는 선택한 AI 공급자에게 전달됩니다. 토스 계좌번호와 인증정보는 제외합니다. 웹 검색어에는 공개 기업명·주제만 사용하도록 공통 조사 지침을 적용합니다.

로컬 데이터는 `data/oh-my-stock.sqlite`에 저장됩니다. 별도 암호화는 하지 않습니다. **설정 → 데이터 백업 다운로드**로 JSON을 내보낼 수 있습니다. 서버를 종료한 상태에서 `data` 폴더를 복사하면 DB 백업·복원이 가능합니다. `.env`, DB, `.runtime`과 백업은 저장소에 커밋하지 마세요.

```powershell
pnpm test             # 외부 연결 없는 계산·API·분석 흐름 테스트
pnpm build            # TypeScript 및 Vite 프로덕션 빌드
pnpm audit            # 전체 의존성 취약점 확인
pnpm check:ai         # 가상 자료로 CLI 구조화 응답 검사 (AI 사용량 소비)
pnpm check:research   # 공개 Adobe 질문으로 실제 웹 검색 검사 (AI 사용량 소비)
pnpm check:daily      # 개인 정보 없이 공개 시장 브리핑 검사 (AI 사용량 소비)
```

`pnpm check:toss`는 별도 토큰을 발급하므로 OMS 서버를 종료한 상태에서만 사용하세요. 토스는 클라이언트당 한 토큰만 유효합니다.

현재 자동화는 **질문 또는 새로고침 → 조사 → 한국어 분석 → 저장**입니다. 앱이 꺼져 있을 때 실행되는 정기 브리핑·알림, 자동 주문, PDF 업로드, 배당·실현손익·정교한 ETF 중복 노출 분석은 아직 구현하지 않았습니다.
