## 현재 제한

2026-09-07 가독성 변경은 격리 QA 서버의 공개 자료 화면에서 데스크톱 1440×1000과 모바일 390×844로 확인했다. 모바일 본문 17px, 요약 줄 높이 32.3px, 문서/전체 스크롤 폭 375px 일치를 확인했다. 저장된 답변을 수정하거나 요약하지 않고 표시 문단과 여백을 변경했다. Linux 서버·Tailscale Serve 자체의 실제 실행, 휴대폰 셀룰러 접속과 서버 재부팅은 아직 검사하지 않았다.

추가로 1100px 화면의 모델 비교는 한 열로 배치되고 문서/스크롤 폭 1085px가 일치했다. 모델 전환·모바일 출처 펼치기가 동작하며 브라우저 콘솔 오류·경고는 0건이었다. 최종 로컬 서버 재시작 후 HTTP 200, 기존 보유 9개·분석 3개와 두 CLI 인증 상태를 API로 확인했다. 커밋 대상 63개 파일의 실제 환경 비밀값·인증키 패턴 검사와 Git 공백 검사를 통과했다.

1. 로그인·구독이 허용하는 모델과 사용량 범위에서 동작한다. ChatGPT 웹 채팅과 CLI가 동일한 기능·한도를 보장하는 것은 아니다.
2. 웹 검색 실패, 접근 불가 원문, 모델의 잘못된 읽기·단위 환산·출처 생성 가능성이 있다. 형식·인용 검증만으로 투자 사실을 검증하지 않는다.
3. 영문 IR·공시 원문 URL은 유지한다. 보고서와 출처 설명은 한국어지만 외부 원문 사이트의 언어를 변경하지는 않는다.
4. 체결 시세는 거래가 있을 때 갱신된다. 주말 연결 검증은 장중 지연·장애·재접속을 장시간 검증한 결과가 아니다.
5. 전체 계좌 수익률, 실현손익·배당·세금·수수료·실제 환차익, ETF 내부 중복 노출은 미구현이다. 현재 보유분 평가손익과 관측 자산 추이를 제공한다.
6. 현재 화면의 자산 차트는 최근 300개 스냅샷이며 전체 기록은 DB에 보존한다. 과거 관측이 없으면 과거 차트를 만들지 않는다.
7. 예약 실행·푸시 알림, 자동 주문, PDF 업로드, JSON 백업 복원 UI는 미구현이다. CSV는 쉼표가 포함된 인용 필드를 지원하지 않는 단순 형식이다.
8. 로컬 DB는 암호화하지 않는다. 분석 시 선택한 포트폴리오 자료는 해당 AI 공급자로 전송된다. RSS 보유 티커 전송은 기본 비활성이다.
9. 상세 trace는 이번 버전 이후 실행부터 저장된다. 이전 보고서의 실제 전송문은 소급 복원할 수 없다. 저장한 프로필도 선택한 AI 공급자에게 전달된다.
10. 로컬 실행 확인은 원격 모델의 활동을 보장하지 않는다. 완료율·완료 예상 시간은 계산하지 않는다. 일정 시각과 출처의 사실 정확성은 모델이 잘못 해석할 수 있어 원문 확인이 필요하다.
